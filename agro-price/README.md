# agro-price — 农化制品价格跟踪

以广信股份（603599）的营收结构为骨架，跟踪其主营产品（农药原药 / 中间体）的
市场价格走势，将"产品价格 → 出厂价/毛利率 → 公司业绩"的传导链可视化。

## 页面

<https://masterwusama.github.io/agro-price/>

- **营收结构卡**：2025 年报口径（农药产品 54.5%、中间体产品 44.58%），点击分类筛选产品
- **产品卡片**：最新价、周/月/年初涨跌、数据期数
- **价格走势图**：ECharts 折线图，支持多产品对比、归一化对比（基准=100）、时间范围切换

## 工作原理

```
GitHub Actions（定时任务，每天 2 次）
   ├─ 中农立华原药价格指数（www.sino-agri-sal.com）→ 原药主序列（每周全量重抓）
   ├─ 生意社商品报价动态 + 报价中心（mprice）→ 中间体主序列（增量累积）
   └─ 3456.tv 行情历史 → 2020~2025 回填（已停更）
        ↓ 解析/合并 → data/products.json
   GitHub Pages 静态托管 → https://masterwusama.github.io/agro-price/
```

## 数据源

| 来源 | 内容 | 说明 |
|------|------|------|
| 中农立华原药价格指数（官网） | 多菌灵/甲基硫菌灵/草甘膦等原药周度报价（2023.07 至今） | 每周更新，单一渠道最可比；原药品种主序列 |
| 生意社商品报价动态（100ppi.com） | 敌草隆/邻苯二胺/对硝基氯化苯等企业报价（元/吨） | 每周 2~4 次更新，多交易商，按样本最多交易商取主序列 |
| 生意社报价中心（mprice） | 各品种最新报价表格（市场价/出厂价） | 按商品 ID 直抓，翻 5 页；多交易商可配置按日取中位数合并，自动剔除离群交易商 |
| 3456.tv 行情文章 | 2020~2025 年杀菌剂/除草剂/中间体历史价格 | 已停更（2025 年），仅用于主序列时间范围外的历史回填 |

## 添加 / 删除品种

编辑 `scripts/fetch_prices.py` 中的 `PRODUCTS` 列表：

```python
{
    'id': 'benmijiahuanzuo', 'name': '苯醚甲环唑', 'category': '杀菌剂', 'spec': '95%',
    'primary': 'sino-agri',           # 主序列来源：sino-agri（中农立华）/ sunsirs（生意社）
    'sunsirs_seed': 'https://www.100ppi.com/news/detail-XXXXXXX.html',  # 生意社任意一篇报价动态
    'mprice_ids': [(1922, '邻苯二胺')],  # 可选：生意社报价中心商品 ID + 页面显示名
    'merge_all_traders': True,       # 可选：mprice 多交易商按日取中位数合并（默认取样本最多单一交易商）
}
```

- `primary='sino-agri'`：原药品种建议用中农立华周度序列（每周全量重抓，最可比）
- `primary='sunsirs'`：中间体（或中农立华不常报的品种，如敌草隆）用生意社连续报价；
  可用 `exclude_sources: ['sino-agri']` 弃用其他源
- `sunsirs_seed` 填该品种任意一篇"商品报价动态"文章链接（脚本会自动定位栏目页翻页抓取）
- `mprice_ids` 填生意社报价中心商品 ID（页面名与品种名不一致时用元组指定显示名；
  别名商品也可多 ID 合并，如对硝基氯化苯同时收录 2345"对硝基氯苯"、1535"对硝基氯化苯"、
  2364"对氯硝基苯"三个 ID）
- `merge_all_traders: True`：mprice 多交易商报价全部按日取中位数合并（单交易商缺报时
  由其他交易商补位，更连续）；默认按样本最多交易商取主序列
- mprice 数据自动剔除离群交易商（价格中位数与全量偏差 > 25% 且样本 >= 3，如混入
  高纯规格报价的南通众合），防止按日聚合时产生突变尖峰
- 生意社没有的品种（如甲基硫菌灵）`sunsirs_seed` 可留 `None`，仅靠中农立华 + 3456.tv

## 注意

- **更新频率**：定时任务每天 2 次（北京 9:00 / 21:00）；中农立华每周更新、生意社报价动态每周 2~4 次，频率足够
- **数据源**：中农立华官网与生意社（100ppi.com）均为公开网页，无需 token；若反爬升级需相应调整脚本（已内置重试与延时）
- **报价口径**：中农立华为原药价格指数（万元/吨）、生意社为企业报价（元/吨）、3456.tv 为市场行情报价，均已统一为元/吨；
  各品种主序列固定单一来源，其他源只填主序列时间范围外的日期段，避免不同口径交错造成假突变
- **增量策略**：中农立华每次全量重抓（文章数有限），生意社按栏目翻 5 页增量累积（历史保留在 products.json 中）；
  主序列以本轮 fresh 抓取为准，旧文件仅补 fresh 未覆盖的更早历史，避免旧聚合值重复参与聚合
- **数据仅供个人学习研究**，商业使用请确认数据源协议
