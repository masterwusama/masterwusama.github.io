# agro-price — 农化制品价格跟踪

以广信股份（603599）的营收结构为骨架，跟踪其主营产品（农药原药 / 中间体）的
市场价格走势，将"产品价格 → 出厂价/毛利率 → 公司业绩"的传导链可视化。

## 页面

<https://masterwusama.github.io/agro-price/>

- **营收结构卡**：2025 年报口径（农药产品 54.5%、中间体产品 44.58%），点击分类筛选产品
- **产品卡片**：最新价、周/月/年初涨跌、数据期数
- **价格走势图**：ECharts 折线图，支持多产品对比、归一化对比（基准=100）、时间范围切换

## 工作原理

```
GitHub Actions（定时任务，每天 2 次）
   └─ Python 抓取生意社"商品报价动态" → 解析品种/价格/日期 → 合并进 data/products.json
        （首次运行还会从 3456.tv 回填 2022~2025 历史行情）
        ↓
   GitHub Pages 静态托管 → https://masterwusama.github.io/agro-price/
```

## 数据源

| 来源 | 内容 | 说明 |
|------|------|------|
| 生意社商品报价动态 | 多菌灵/敌草隆/邻苯二胺/对硝基氯化苯等企业报价（元/吨） | 每周 2~4 次更新，可沿"相关商品"链接回溯历史 |
| 3456.tv 行情文章 | 2022~2025 年杀菌剂/除草剂/中间体历史价格 | 已停更，仅用于历史回填 |

数据文件：`data/products.json`，结构：

```jsonc
{
  "updated_at": "2026-08-22T09:00:00+08:00",
  "products": [
    {
      "id": "carbendazim",
      "name": "多菌灵",
      "category": "杀菌剂",      // 杀菌剂 / 除草剂 / 中间体
      "spec": "99%",
      "unit": "元/吨",
      "prices": [
        { "date": "2026-08-21", "price": 40000, "source": "sunsirs", "note": "苏州市森菲达化工" }
      ]
    }
  ]
}
```

## 添加 / 删除品种

编辑 `scripts/fetch_prices.py` 中的 `PRODUCTS` 列表：

```python
{
    'id': 'benmijiahuanzuo', 'name': '苯醚甲环唑', 'category': '杀菌剂', 'spec': '95%',
    'sunsirs_seed': 'https://www.100ppi.com/news/detail-XXXXXXX.html',  # 该品种任意一篇报价动态
}
```

`sunsirs_seed` 填该品种任意一篇"商品报价动态"文章链接即可（脚本会自动定位栏目页并翻页抓全历史）。
生意社没有的品种（如甲基硫菌灵）可留 `None`，仅靠 3456.tv 回填历史。

## 本地调试

```bash
# 无需安装依赖（仅标准库）
python scripts/fetch_prices.py
```

输出到 `data/products.json`，直接打开 `index.html` 预览。

## 注意

- **更新频率**：定时任务每天 2 次（北京 9:00 / 21:00）；生意社报价动态每周 2~4 次，频率足够
- **数据源**：生意社（100ppi.com）公开网页，无需 token；若反爬升级需相应调整脚本（已内置重试与延时）
- **报价口径**：生意社为企业报价（单交易商），3456.tv 为市场行情报价，两者已统一为元/吨；
  同一品种同一天多条记录时以最新抓取为准
- **数据仅供个人学习研究**，商业使用请确认数据源协议
